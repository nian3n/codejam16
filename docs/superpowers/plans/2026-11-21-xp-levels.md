# XP and Levels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Players earn XP for signs, modules, a win and time left. They climb levels with no cap, and they see a round summary on the end screen.

**Architecture:** The server computes each player's round XP when the round ends and sends it in the state (`round_xp`). The browser saves the round's non-sign XP under the round id in `localStorage`. It adds the existing sign credits (5 XP each) to get the total, and it turns the total into a level with pure functions in a new DOM-free module.

**Tech Stack:** FastAPI WebSockets, pytest, vanilla ES modules, Node for the JS unit test (pattern of `tests/test_sequence.py`).

**Spec:** `docs/superpowers/specs/2026-11-21-xp-levels-design.md`

## Global Constraints

- XP values: sign 5 per practice credit. Module defused 10 each. Bomb defused: beginner 50, intermediate 75, advanced 100, custom 75. Time left: 1 for each full 2 s left, win only.
- Level n to n + 1 needs `250 + 100 × (n − 1)` XP. Level 1 starts at 0.
- Titles: Beginner (1–2), Developing (3–4), Practiced (5–6), Skilled (7–9), Accomplished (10 and up).
- Saved key: `ep:round-xp:<profile id>:<round id>`, value = round total minus the sign part.
- No client decides the XP of a round. "Exit game" gives no end-of-round XP.
- Every new source file starts with `# Owner: Teammate 1 (Game, scenes, widgets)` or `// Owner: ...`.
- STE wording for user-visible text and `.md` files.

## Review Focus

- A reload on the end screen: the same `round_xp` arrives again. The total must not grow. (Task 2 test: saving one round twice.)
- The handler acks credits (`practice_saved`), which removes them from `practice_credits`. The round's sign count must still be right at the end. (Task 1 test: ack before the end.)
- A loss by timeout: `ended_left` is 0, and the summary has no win and no time lines. (Task 1 test.)
- "Again" starts a new round: the old `round_xp` must leave the state, and the new round counts from zero. (Task 1 test.)
- A profile with old credits and no round results: level from credits alone, no error. (Task 2 test.)
